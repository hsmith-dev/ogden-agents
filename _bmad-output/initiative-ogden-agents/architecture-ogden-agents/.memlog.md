- (decision) [ADOPTED] AD-24 added (CAP-24, architecture pass 2026-10-07): remote run worktree sync. A remote target reuses AD-17's run worktree unchanged (still created by VcsPort in the controller's data directory, from the commit every local run uses); before a remote run starts, the server streams that worktree's tracked contents to a matching path on the remote machine over the same SSH connection used to spawn the agent (git archive/bundle piped through the SSH session), never through the project's origin remote, so the remote machine needs and gets no origin credentials.
